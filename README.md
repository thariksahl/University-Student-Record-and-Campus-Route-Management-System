# CIT300 Graded Practical Assignment 1
## University Student Record and Campus Route Management System

### Project purpose
This Java console application demonstrates the data structures required by the CIT300 assignment:
- Linked List - student record storage and management
- Stack - recent action history
- Queue - student service requests
- Binary Search Tree (BST) - student organization/search by Student ID
- Hash Table - efficient Student ID search
- Graph using an adjacency list - campus locations and connections
- BFS - campus graph traversal

### How to run
1. Open the project in Eclipse.
2. Make sure all `.java` files are inside the source folder.
3. Open `Main.java`.
4. Run `Main.java` as a Java Application.
5. Test each menu option.
